# VASTORA Luxury Interiors – Website & Staff Tools

| File | What it is |
|---|---|
| `index.html` | Customer-facing luxury interiors showroom website |
| `staff-dashboard.html` | Private staff dashboard (senior / junior / factory / field roles) |
| `staff-dashboard-demo.html` | Dashboard demo version |
| `site-studio.html` | Site Studio (design editor) |
| `showroom-suite-preview.html` | All-in-one showroom suite preview |

## Important
- Keep this repository **Private**. It contains the staff dashboard.
- Pages that were built to use claude.ai features (shared data, chat sync, saved logins) work fully on claude.ai. Outside claude.ai they open and display, but saving or syncing between users needs a real backend.
- Do not link the staff pages from the public website.
