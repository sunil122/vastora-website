# Vastora Living — Website Preview

This is the first visual direction for the Vastora Living brand website.

## Preview structure
- `index.html` — responsive single-page website prototype
- All copy, sections, imagery, colours and typography are intentionally easy to revise in one file.
- Images currently use remote Unsplash image URLs as temporary visual placeholders.
- The enquiry form is a visual prototype only; connect it to a real email/CRM endpoint before launch.
- Contact details, office/showroom address, project photography and final product imagery are still to be supplied.

## Brand
- Name: Vastora Living
- Slogan: The Art of Better Living
- Divisions: Vastora Living, Vastora Furniture, Vastora Build, Vastora Global, Vastora Atelier

This is a review build, not the final production website.
